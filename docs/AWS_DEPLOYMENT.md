# AWS deployment
No AWS resources are deployed by this repository. Review Terraform, configure credentials using an approved AWS profile, prepare the Lambda deployment zip, select the target environment and region, then run terraform init/plan and inspect the plan before apply. Provision AWS IoT certificates and attach a least-privilege policy restricted to the device's telemetry/status/commands topics. Configure device certificate material outside source control. Use remote state with encryption and locking for shared environments. Production apply must be an explicit operator action.
